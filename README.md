Hotel Management System
A simple hotel management system built with Python that allows management of rooms, bookings, guests, and staff.

Features
Room management (add, update, delete)
Guest registration
Booking management
Staff management
Reports generation
Setup
Make sure you have Python 3.8+ installed
Clone this repository
Install the required dependencies:
pip install -r requirements.txt
Run the application:
python main.py
Database
The system uses SQLite for data storage. The database file will be created automatically on first run.
