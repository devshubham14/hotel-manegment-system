# Hotel Management System

A simple hotel management system built with Python that allows management of rooms, bookings, guests, and staff.

## Features
- Room management (add, update, delete)
- Guest registration
- Booking management
- Staff management
- Reports generation

## Setup
1. Make sure you have Python 3.8+ installed
2. Clone this repository
3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Run the application:
   ```
   python main.py
   ```

## Database
The system uses SQLite for data storage. The database file will be created automatically on first run.
